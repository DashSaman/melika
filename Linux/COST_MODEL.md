# هزینه و ظرفیت — مدل قابل محاسبه، نه وعده رایگان نامحدود

تاریخ مشاهده قیمت‌ها: **2026-10-17**. واحد قیمت‌های زیر **تومان** است، نه ریال. این سند پیشنهاد خرید یا تعهد تعرفه نیست؛ صورتحساب، مالیات، منطقه، سهمیه و وضعیت پنل باید پیش از پرداخت تأیید شود. هیچ سرویسی در این تحقیق خریداری نشده است.

## ۱. مرجع قیمت رسمی

از بخش **IaaS** صفحه لیارا، نه PaaS یا دیتابیس مدیریت‌شده: ۱vCPU/۲GB RAM/۲۰GB SSD برابر ۱٬۴۷۵٬۰۰۰ تومان در ماه؛ ۲vCPU/۴GB/۴۰GB برابر ۲٬۶۵۰٬۰۰۰؛ ۴vCPU/۸GB/۸۰GB برابر ۴٬۶۰۰٬۰۰۰. IPv4 جدا ۲۰۰٬۰۰۰ تومان ماهانه نشان داده شده است. همان صفحه برای «ترافیک دانلود» ۲٬۵۰۰ تومان/GB و upload رایگان درج می‌کند؛ جهت دقیق ترافیک قابل صورتحساب و استثناها را در قرارداد روشن کنید. این‌ها نمونه محاسبه‌اند، نه ارزان‌ترین بازار. [S23](SOURCES.md)

فضای ابری آروان: پایه رایگان با ۵GB storage و ۲۰GB traffic؛ رشد ۱٬۵۰۰٬۰۰۰ تومان/ماه با ۵۰۰GB storage و ۲TB traffic در جدول مشاهده‌شده. تعداد درخواست و هزینه مازاد جدا هستند. در جدول مازاد، storage تا ۵TB برابر ۳٬۰۰۰ تومان/GB دیده می‌شود ولی FAQ همان صفحه ۱٬۴۰۰ ذکر می‌کند؛ این اختلاف حل نشده است. نرخ دانلود مازادِ طبقه اول ۸۵۰ تومان/GB دیده می‌شود. برای بودجه قطعی، استعلام پنل لازم است. ## ۲. سناریوها

| سناریو | معماری مفروض | هزینه ثابت نمونه | هزینه‌های خارج عدد |
|---|---|---|---|
| A0: استفاده از سرور موجود | gateway، SQLite، metadata و CAS محدود روی دیسک موجود | خرید سرور/دیسک اضافه ممکن است صفر باشد؛ مصرف منابع صفر نیست. | ظرفیت واقعی، برق/نگهداری، پهنای باند، دامنه و backup |
| A1: MVP روی VM تازه | یک VM ۱vCPU/۲GB/۲۰GB + IPv4 طبق نمونه لیارا | ۱٬۶۷۵٬۰۰۰ تومان/ماه = ۱٬۴۷۵٬۰۰۰ + ۲۰۰٬۰۰۰ | ترافیک، دامنه، مالیات/اقلام پنل، نیروی نگهداری |
| B: سرویس جامعه کوچک | دو VM ۲vCPU/۴GB/۴۰GB + IPv4، با failure domain مستقلِ تأییدشده | مرجع محاسبه ۵٬۷۰۰٬۰۰۰ تومان/ماه = ۲ × ۲٬۸۵۰٬۰۰۰ | storage اضافی، شبکه، پایش، backup مستقل؛ استقلال دو VM در یک فروشنده فرض نشود. |
| B با storage رشد | سناریوی B + پلن ۵۰۰GB نمونه آروان | جمع مرجع ۷٬۲۰۰٬۰۰۰ تومان/ماه قبل از مازاد | سهمیه request/traffic، مالیات، قرارداد و اختلاف تعرفه مازاد |
| C: مقیاس گسترده | چند edge، PostgreSQL، object store، اپراتور و قرارداد ظرفیت | **نامعلوم؛ نیازمند workload و پیش‌فاکتور** | ترافیک غالب، HA، DDoS، monitoring و عملیات |

این مشخصات sizing پیشنهادی‌اند و benchmark نشده‌اند. قیمت دو VM نمونه، تضمین این نیست که برای تعداد خاص کاربر کافی‌اند. هیچ فرضی درباره هزاران کاربر هم‌زمان بدون آزمون بار پذیرفته نیست.

## ۳. فرمول محاسبه ماهانه

```text
monthly = compute + public_IP + domain_monthly_share
        + object_storage_plan + storage_overage
        + gateway_egress + storage_egress
        + requests + monitoring + backup + operations + taxes_if_applicable
```

تمام unknownها پارامتر بمانند. هر بایت فقط در محل صورتحساب مربوط حساب شود؛ ترافیک redirectشده را همزمان به‌عنوان egress اصلی gateway و storage نشمارید. برعکس، دانلود کامل برای hash verification، sync و warmup را فراموش نکنید.

اگر فایل ۱۰۰MiB به ۱۰۰۰ client مستقیم از ارائه‌دهنده برود، حدود ۹۷٫۶۶GiB بدنه فایل از آن ارائه‌دهنده منتقل می‌شود، نه از gateway. gateway هنوز metadata/302/health traffic و هزینه عملیات دارد. اگر همان فایل proxy شود، همین بدنه در خروجی gateway هم وجود دارد. این مثال حسابی است، نه ترافیک اندازه‌گیری‌شده یا تعرفه گیگابایت اعشاری.

ترافیک کاربر نهایی، هزینه اپراتور میرور و هزینه ما سه موضوع جدا هستند. تعرفه داخلی/رایگان اپلیکیشن را به دانلود همه نوع فایل و همه ISP تعمیم ندهید. صفحه قوانین روبیکا فقط شرایط خاصی برای انواع معینی از ترافیک بیان می‌کند؛ storage «رایگان» به معنی دانلود عمومی رایگان نیست. [S20](SOURCES.md)

## ۴. ظرفیت و کاهش هزینه

CAS بر اساس SHA، حذف فایل تکراری، انتخاب architecture محدود، نگهداری versionهای لازم، cache pinning اقلام حیاتی و TTL کنترل‌شده metadata، اهرم‌های اولیه‌اند. profile-based mirroring از آرشیو بی‌هدف هزاران پروژه اولویت بالاتری دارد.

حداقل دیسک شامل OS، Docker layers، dependencyهای خود برنامه، DB/WAL، metadata قدیم/جدید، staging، لاگ و کپی حیاتی است. «ذخیره فقط شکاف‌ها» این اقلام را حذف نمی‌کند. مقدار ۲۰GB شامل OS است؛ ۵GiB CAS و ۱GiB metadata فقط با فضای آزاد واقعی می‌تواند تخصیص یابد.

محدودیت سخت upload/download و alarm هزینه پیش از فعال‌سازی backend تعریف شود. از free tier بالاتر رفتن نیازمند تأیید مالک است. عدم وجود صورتحساب روبیکا مجوز مصرف نامحدود یا ایجاد حساب برای عبور از سهمیه نیست.

## ۵. هزینه زمان و حدود برنامه یک‌روزه

۸–۱۲ ساعت، **بودجه تلاش مهندسی برای MVP محدود** است؛ زمان دسترسی/مجوز/انتقال داده، مدت مشاهده ۲۴/۷۲ساعته و رفع موانع ISP در آن تضمین نمی‌شود. تیم یا Codex باید در پایان، بودجه مصرف‌شده و قابلیت‌های واقعاً آزموده را گزارش کند. ساخت محصول ملی با نگهداری ۲۴ساعته هزینه عملیاتی مستقل دارد.

قبل از هر خرید، نتیجه پروب ایران و اندازه واقعی manifest را به این مدل بدهید. بدون آن، انتخاب دیتاسنتر و storage صرفاً حدس ظرفیت خواهد بود.
