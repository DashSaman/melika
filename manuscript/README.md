# وضعیت متن سمینار

**هنوز متن کامل یا پیش‌نویس علمیِ قابل ارائه در این پوشه وجود ندارد.** فایل‌های پژوهش مقدماتی را به‌جای متن نهایی معرفی نکن.

متن باید مطابق یازده بخش MASTER_PROMPT نوشته شود. مسیرهای پیشنهادی برای ادامه: `01_frontmatter.fa.md`، `02_introduction.fa.md`، `03_theory.fa.md`، `04_mechanisms.fa.md`، `05_literature.fa.md`، پوشه `06_articles/`، `07_visual_synthesis.fa.md`، `08_discussion.fa.md`، `09_implications.fa.md`، `10_conclusion.fa.md` و `11_references.md`.

این نام‌ها برنامه‌اند، نه فایل‌های موجود. هر بخش فقط پس از نگارش واقعی، ارجاع و بازخوانی وارد امتیاز پیشرفت شود. رکوردهای SOURCE_LEDGER فقط وقتی در فهرست منابع نهایی قرار گیرند که واقعاً در متن استفاده شده باشند.
