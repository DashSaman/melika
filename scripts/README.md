# ابزارهای ساخت و کنترل

در این checkpoint هنوز سازنده Word یا ابزار کنترل ارجاعات پیاده‌سازی نشده است. دستور اجرایی ساخت نهایی وجود ندارد؛ هیچ فرمان خیالی معرفی نشود.

هنگام پیاده‌سازی، نسخه ابزارها، قلم در دسترس، تنظیم RTL، فیلدهای فهرست/کپشن، تبدیل و کنترل صفحات ثبت و خود ابزارها آزموده شوند. آزمون فایل‌های برنامه‌ریزی یا محاسبه درصد، جایگزین QA علمی/صفحه‌آرایی نیست.
